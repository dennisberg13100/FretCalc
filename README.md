# FretCalc

Aplicativo desenvolvido em React Native com Expo para calcular o espaçamento dos trastes em escalas de instrumentos musicais, auxiliando luthiers na construção e no planejamento de instrumentos de cordas.

## Funcionalidades planejadas
- [ ] Informar o comprimento da escala e o número de trastes.
- [ ] Selecionar a precisão das medidas (1 mm, 0,5 mm, 0,1 mm e 0,01 mm).
- [ ] Calcular a posição de cada traste e a distância entre trastes consecutivos.
- [ ] Visualizar a escala em um desenho técnico.
- [ ] Exportar e imprimir as medidas.
